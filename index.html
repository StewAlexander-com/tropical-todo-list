Backup & restore

Your tasks never leave this device. Snapshots are plain JSON you control. Merge keeps newer tasks and folder names; ties keep this device’s copy. Older backups without name timestamps keep your existing custom folder names.

Manual

Export a snapshotDownload all tasks as a dated JSON file.
Restore from fileMerge preserves newer edits. Replace restores the snapshot instead.

Auto-backup folder

Grant a backup folderWrites troplist-latest.json plus rotating dated snapshots. Keeps last 10 dated files.
Stop auto-backup and forget the folder.

Clear everythingDelete all tasks on this device. Cannot be undone.

Find vs add

Type in the top bar to find existing tasks as you type. To create a task, tap Add or press Enter. Dates, repeats, tags, and folder choices still work. Tap × or press Esc to clear the text.

Folders

Tap to open. Tap again to hide its contents. Tap another folder to switch, or All tasks to return to the full list.

Down chevron + outline: open. Up chevron: closed. Opening a folder filters your list; it doesn’t move tasks.

Wording suggests a folder. Adding a time also files that suggestion. Choose a different folder before Add to override it. Use Rename folders below, choose a folder, edit its name, and tap Save. Cancel leaves it unchanged; suggestions still follow the same folder.
